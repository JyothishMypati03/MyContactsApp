# MyContacts App

A Java-based console application that demonstrates Object-Oriented Programming (OOP), Design Patterns, Collections Framework, Java 8 features, and Core Java concepts through a Contact Management System.

---

## 📖 Project Overview

MyContacts App is built use case by use case to simulate a real-world contact management application.

The goal of this project is to strengthen Java fundamentals while applying software engineering principles such as:

- Object-Oriented Programming
- Design Patterns
- Java Collections Framework
- Java 8 Functional Programming
- Exception Handling
- File Handling
- Regular Expressions
- Unit Testing
- Clean Code Practices

## ▶️ How to Run

1. Clone the repository

```bash
git clone https://github.com/your-username/MyContactsApp.git
```

2. Open the project in IntelliJ IDEA or Eclipse.

3. Build the project using Maven.

```bash
mvn clean install
```

4. Run the main class.
